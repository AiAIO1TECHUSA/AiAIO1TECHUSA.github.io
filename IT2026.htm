Network World

To get started with entering command scripts, open the Command Prompt and write your first network commands:

ipconfig /flushdns
netsh int ip delete arpcache
ipconfig /release
ipconfig /renew

Ping Test

Ping to test your host server on a remote address by typing the following command:

ping 8.8.8.8

If it reaches Google's DNS server, your DNS server is working and you have internet connectivity.

If you still have issues, clear your browser history and cache completely.

Virus Scan

You can scan for viruses in three easy steps on Windows 11:

  1. Right-click the Windows Logo
  2. Select "Windows Terminal (Admin)" or "Command Prompt"
  3. Run as administrator and type:
MpCmdRun -Scan -ScanType 3 -File PATH\TO\FOLDER-FILES

Restore Without Disk

To change the guest account to an administrator account in Windows, follow these steps:

  1. Sign in with an Administrator account
  2. Open Settings
  3. Navigate to Accounts
  4. Select the guest account and promote it

Registry Backup: Always create backups before making registry changes:

xcopy c:\ e:\ /s /e /h /i /c /y

Safe Boot: Hold down the Windows Logo Key and press X. Select Run, type msconfig and press Enter. Go to the Boot tab and select Safe Boot.

PowerShell ISE

To create a new script file in PowerShell ISE, click the "New" button on the toolbar or go to File > New. You can then start typing your script.

powershell_ise.exe C:\PSBackup_AD_DC.ps1

To create a user account on PowerShell, use the New-LocalUser cmdlet:

New-LocalUser -Name "user_name" -Description "Description of your new account." -NoPassword

Common PowerShell Cmdlets:

  • Get-Command: View all PowerShell commands installed on your computer
  • Get-Help: Find information for commands, concepts, and functions
  • Clear-Host: Clear the PowerShell console screen
  • Set-Location: Change the current location in PowerShell
  • Get-ChildItem: List all files and directories in the current directory
  • Get-Alias: List all aliases for PowerShell commands
