PC Network Performance, Security Basics, and Maintenance

Network Troubleshooting Commands

Run these from an administrator Command Prompt when diagnosing connectivity problems. Work through them in order, from the local machine outward.

ipconfig /release
ipconfig /renew
ipconfig /flushdns
netsh interface ip delete arpcache
ping 8.8.8.8
ping google.com
nslookup google.com
nslookup google.com 8.8.8.8
tracert google.com

Key point: ping 8.8.8.8 tests raw internet connectivity by IP address and does not test DNS. If ping google.com fails but ping 8.8.8.8 succeeds, the problem is DNS. If tracert reports that it cannot resolve the target system name, the problem is also DNS.

Windows Defender Firewall

Back up your rules before changing anything, then restore defaults if the rule set has become cluttered or untrustworthy.

netsh advfirewall export "C:\fw-backup.wfw"
netsh advfirewall reset

Keep the Public network profile strict. Block inbound connections by default, enable logging, and make sure your Wi-Fi network is classified as Public. Create block rules for specific remote addresses in wf.msc rather than relying on a blacklist feature, since Windows doesn't include one.

Background Services and System Speed

Use Task Manager to reduce load. The Startup apps tab controls what launches at boot, and the Processes tab shows which programs consume CPU, memory, disk, or network bandwidth. Stopping a service in the Services tab is temporary. For permanent changes, use msconfig with Hide all Microsoft services checked, then disable third-party services you don't need.

Do not disable Windows Defender Antivirus, Windows Update, Windows Defender Firewall (mpssvc), or the Windows Event Log.

Malware Checks

Run the Microsoft Malicious Software Removal Tool monthly, and use the Kaspersky Virus Removal Tool or Kaspersky Rescue Disk when you suspect a rootkit. Run one third-party scanner at a time to avoid conflicts.

schtasks /create /tn "Monthly Malware Scan" /tr "%SystemRoot%\System32\MRT.exe /Q /F:Y" /sc monthly /d 1 /st 02:00 /ru SYSTEM /rl HIGHEST

Wi-Fi and Network Segmentation

Hiding the Wi-Fi network name does not provide real security. Use WPA3, or WPA2-AES if your equipment doesn't support WPA3, with a long passphrase. Place public or guest Wi-Fi on its own VLAN and route it to the internet only. Do not bridge public Wi-Fi directly into the business LAN or substation VLANs. Use default-deny rules between zones and allow only the specific hosts and ports that must communicate.
